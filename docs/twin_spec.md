## 1) backend/twin (A ajanı) — saf Python, DB/Streamlit bilmez
`build_twin_data(layout, routes, sim, *, scenario_label="Mevcut", window_s=None) -> TwinData`.
Ön koşul (Türkçe ValueError): `sim.layout_id == layout.id == routes.layout_id`; logdaki her (from,to,vehicle) için `routes.get(...)` bulunmalı ve reachable.
Enterpolasyon: taşıma [ts+load, ts+load+travel] aralığında Route.points yay uzunluğuna göre `u=(t−t0)/(t1−t0)`, `s=u·len`, `cum` üzerinde ikili arama + doğrusal ara değer. `travel=(tc−ts)−load−unload`; `|travel−d/speed|>1e-6` ise uyarı notu + [ts,tc] ölçekleme (varış anı her zaman logdaki COMPLETED). Python referansı `position_at(data, t)` (test + JS referansı).
Segs: 0 kuyruk (QUEUE_ENTERED→PROCESS_STARTED, aynı istasyon), 1 işlem, 2 blokaj/çıkış bekleme (FINISHED→TRANSPORT_REQUESTED), 3 araç bekleme (REQUESTED→STARTED, `out` noktasında), 4 yükleme, 5 taşıma, 6 boşaltma (`inp` noktasında). Bitmemiş segmentte t1=t_end; sıfır uzunluklu saklanır, çizilmez.
VSegs: IDLE/WORK(operatör istasyonda işlem)/LOAD/TRAVEL/UNLOAD. `vehicles` = `sim.config.resources` adetinden `{type}-{k}`; kullanılmayan araç da listelenir.
series (adım fonksiyonu, Python'da hesaplanır): `wip`, `completed_units` (pencerede ENTITY_COMPLETED batch_size toplamı), her istasyon için `queue_<id>`, `busy_<id>`, `maxq_<id>`; araç tipi başına `busy_<tip>`.
consistency (n=1 ve kesik değilse; yuvarlamadan ÖNCE): completed_units==ref.completed (ref = sim.kpis veya n>1'de replication_kpis[0]); WIP integrali/pencere==kpis.avg_wip (rel 1e-9); istasyon busy/(kapasite·pencere)==utilization; pencere max queue_len==max_queue_len; araç busy==ResourceStats.busy_s. Kesik logda "kesik log – karşılaştırılmadı" (ok=None). n>1'de istasyon/kaynak karşılaştırması yapılmaz.
Yuvarlama: koordinat/t 2 ondalık. JSON hedefi demo ≤150 KB; >5 MB ise `window_s` ile kırp + not; HTML sert sınır 15 MB.
**Dürüstlük (kritik):** boş seyir UYDURMA: araç görev sonunda bıraktığı noktada "boşta"; sonraki görev farklı noktada başlıyorsa `jump=1` (eski konumda t0'a kadar boşta, t0'da yeni noktada belirir, arada çizgi/hareket YOK); `meta.teleport_count`, notlara "Modellenmeyen boş seyir: N görev farklı noktadan başladı (ışınlanma)". İlk görevden önce konum bilinmez → ref=-1 (park tepsisi, "konum modellenmedi"). `meta.not_modelled` = sim.not_modelled. Kesik log: `truncated=True`, `t_valid_end` = son olay t'sinden küçük güvenli an, kaydırıcı kilitli. Yalnız replikasyon 0 ("Replikasyon 0 / n"). Sayaçlar `series`'ten okunur, SimResult'tan kopyalanmaz.
Testler `tests/test_twin.py`: segment t0 monoton, t0≤t1, varlık zinciri kesintisiz; kind4+5+6 süre toplamı == COMPLETED−STARTED, kind5 == d/speed(1e-6); 200 rastgele t'de taşıma konumu path.pts polyline'ında (<1e-6) (+ koridor dörtgeni/terminal ≤ station_access_max_m; euclidean/manhattan'da yalnız polyline); t=0 sayaçlar 0, t_end tutarlılık demoda hepsi ok; aynı araçta zaman örtüşmesi yok; jump==1 ⇔ başlangıç≠önceki bitiş, teleport_count test içinde hesaplanır; kesik log (MAX_EVENTS monkeypatch=500) truncated+uyarı; kenar: olaysız sim, 0 adetli araç tipi, tek istasyonlu ürün, replications=3, batch_size=3, layout/rota uyuşmazlığı ValueError; TwinData JSON gidiş-dönüş.
